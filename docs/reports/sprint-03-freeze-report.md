# Sprint 3 model freeze and frozen CLI record (S3-AI-02)

- Selection: applied ST's signed freeze decision in `docs/reports/sprint-03-metrics-check.md` (S3-ST-01, PR #20). Random Forest was selected by the precommitted rule (validation F1 0.85 vs Logistic Regression 0.7442; difference greater than 0.001), with threshold 0.5. No further tuning against validation was done.
- Freeze: `ml/freeze_model.py` copied the already trained pipeline `ml/artifacts/candidate_rf.joblib` (S3-AI-01, trained on the 276 training rows) to `ml/models/student_risk_v1.pkl` without refitting. There was no refit on train+validation and the test split was not read.
- Frozen metadata (`ml/models/model_metadata.json`): model_version `student_risk_v1`, model RandomForestClassifier, schema_version `schema-v1`, threshold 0.5, the 31 features in the frozen order, source/split-manifest/train/validation hashes, the unopened test hash, the artifact SHA-256, package versions (numpy 1.26.2, pandas 2.1.4, scikit-learn 1.3.2, joblib 1.3.2), Python 3.12.10 and the link to ST's freeze record.
- CLI: `ml/predict.py` replaces the Sprint 1 toy probe. It loads only the frozen artifact whose SHA-256, threshold, schema version and package versions match the metadata. It validates the request with `ml/contract.py`, reads one JSON request from stdin and writes one JSON result to stdout (model/schema version, threshold, count, and per row the IDs, the class-1 `risk_score` and a boolean `risk_flag`). Diagnostics go to stderr, with exit code 1 on failure, and non-finite scores are rejected.
- Expected-output fixture for W1: `ml/examples/expected_output_v1.json` (frozen model on `ml/examples/valid_two_rows_envelope.json`). Handoff instructions are in `docs/frozen-cli-handoff.md`.
- Commands and exit codes (Windows, Python 3.12.10 in `.venv`, run from the repository root):
  - `python ml\freeze_model.py rf docs/reports/sprint-03-metrics-check.md` → exit 0 ("Frozen RandomForestClassifier as ml\models\student_risk_v1.pkl (student_risk_v1); metadata and expected fixture written")
  - `python ml\check_sprint3_cli.py` → exit 0 ("Frozen CLI checks passed: student_risk_v1"; scores for the 2 synthetic rows [0.2122, 0.746]; "No held-out (test) evaluation performed.")
- What the check covers: the envelope output equals the expected fixture; bare-array input gives the same results; all three invalid fixtures, a non-JSON request and a wrong threshold exit 1 with empty stdout and a message on stderr; flags are booleans that equal `risk_score >= 0.5`.
