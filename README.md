# Student Performance — Sprint 1

Local educational demonstration. Express + EJS + SQLite + a labelled Python toy CLI. Run all commands from this target repository root, not the planning website repository.

## Install after all Sprint 1 contributions are merged

Use Node 24, Python 3.12, PowerShell 7.4+ and Git. Clone https://github.com/tidalu/student-performance.git once, then enter its directory.

```powershell
$ErrorActionPreference = 'Stop'
$PSNativeCommandUseErrorActionPreference = $true
npm ci
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
python -c "import sys; assert sys.version_info[:2] == (3,12)"
if (-not (Test-Path .venv/Scripts/python.exe)) { python -m venv .venv }
& .venv/Scripts/python.exe -m pip install -r requirements.txt
$env:PYTHON_PATH = (Resolve-Path .venv/Scripts/python.exe).Path
```

In local `.env`, replace `SESSION_SECRET` with a random secret generated by `node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"`. Set `PYTHON_PATH` to the absolute interpreter path printed by `Resolve-Path .venv/Scripts/python.exe`. With a Windows path containing spaces, surround the `.env` value with double quotes. Never commit `.env`; each member configures their own path. The shell variable above applies only to the current terminal; `.env` is used by server.js.


Every command must exit 0. Replayed migrations apply no new scripts and seeding creates no duplicate account. The seed creates local synthetic credentials `admin / password123`; use only disposable course data.

## Start and verify

Terminal A, repository root:

```powershell
node server.js
```

Keep Terminal A running. Terminal B, repository root:

```powershell
node scripts/check_sprint1_auth.js
```

The checker must print its success message and exit 0. It creates a uniquely named synthetic account in the local database. It verifies registration, duplicate username/email, weak and mismatched passwords, failed login, CSRF rejection, session rotation, old-session rejection, dashboard access and logout. Open http://localhost:3000/register and repeat the journey in a browser to inspect labels, keyboard focus, errors, narrow layout and dashboard. Stop Terminal A with Ctrl+C when done.

Expected Sprint 1 routes: GET / redirects to /login for guests and /datasets after login; GET/POST /register and /login; POST /logout; authenticated GET /datasets. Upload arrives in Sprint 2, saved runs in Sprint 3, and Evaluation/Help in Sprint 4; their navigation targets may return 404 now. Do not treat those links as finished features.

## Shared AI/W1/W3 contract

Use Mathematics `data/student-mat.csv` only: 395 records. Inference has all 31 canonical features, including G1 and excluding G2/G3. Use `ml/schemas/schema-v1.json`, `ml/contract.py` and fixtures under `ml/examples/`. Bare input arrays return row-result arrays; `{schema_version, rows}` envelopes return run metadata and results. W1's adapter sends an envelope. Sprint 1's model version is `v0.1-toy-contract-spike`; scores are protocol probes, never measured predictions. Sprint 3 replaces predict.py with frozen-model inference.

## Cookie and environment settings

For local HTTP, cookies are HttpOnly, SameSite=Lax and do not use Secure. Never place secrets, databases or virtual environments in Git. Hosted operation is outside this local MVP. Any future HTTPS hosting requires Secure cookies, correct proxy trust and a separate configuration review; the Sprint 1 HTTP configuration is not a hosting recipe.

## Evidence and failures

Record actual commands, exit codes and commit/PR links on the frontend cards. A failing command blocks that handoff. Missing Python: check local `.env` and shell PYTHON_PATH. Missing module: run npm ci from the target root. Connection refused: start Terminal A. Changed port: set APP_URL in Terminal B to the exact local URL before running the authentication checker. Do not invent professor approval or successful test outcomes.
